## 先分清计价单位，再谈贵不贵

同样标“静态住宅 IP”，市面上至少有两种卖法，单位完全不同。

**按 IP 计费**：你买的是一个个代理出口，一个 IP 一个月多少钱，通常 $3.5 上下，折人民币二十多元。这类产品只给你一个 IP 加账号密码，没有 CPU、内存、硬盘，你得自己在指纹浏览器、模拟器或者脚本里配置。按量买还能叠折扣，5 到 9 个 2% off、10 到 49 个 5% off、50 到 199 个 10% off。

**按整机计费**：你买的是一台 KVM 虚拟机，自带 1 个 IPv4、若干核 CPU、内存、硬盘和月流量。价格从几十元到上千元，装什么系统、跑什么程序自己决定。丽萨主机这几条住宅 IP 产品线走的都是这个路子，官方标的是“1 IPv4 IP”加一整套配置。

这两者放在一起比价没有意义。10 个 $3.50 的 IP 一个月是 $35，走 10 到 49 个那档 5% 折扣后 $33.25，你拿到的是 10 个出口；同样的钱在丽萨主机能买三台以上 61.2 元的入门整机，但只有 3 个 IP，多出来的是一整套可自己控制的计算环境。要十个出口就去买十个 IP，要一台能装环境的机器就去买整机，别拿 A 的单价去骂 B 贵。

行业里对“ISP 代理”有两种做法，都叫静态住宅 IP：一种是在当地民宅拉真实宽带、配静态 IPv4、一根线只给一个用户；另一种是在数据中心托管机器，但 IP 段由合作的 ISP 分配，ASN 挂在运营商名下。前者的成本是“租房子 + 装宽带 + 维护 + 等下一批房子拉好线”，扩张极慢；后者成本接近机房 VPS，带宽还给得大方。两种都合理，价格自然不在一个量级。

## 怎么验证你买到的是不是真住宅 IP

价格谈完了，说验真。判断一个 IP 干不干净，按顺序看四项：

1. **ASN 归属**。查这个 IP 的自治系统号登记在家庭宽带运营商名下，还是 IDC/云厂商名下。这是最核心的一项，也是最难造假的一项。
2. **第三方 IP 类型数据库标注**。ipinfo、IP2Location 这类库会标住宅、机房、已知代理段，多个库交叉看。
3. **黑名单与风险评分**。Scamalytics 之类的评分，看这个 IP 段有没有被滥用记录。
4. **DNS 与 WebRTC 是否泄漏**。测试时如果暴露了真实出口，代理配得再漂亮也没用。

四项全过才算干净，缺一项都可能在某天被平台判定异常。

配套的避坑习惯有五条：先测后买，拒绝“不测直接付费”的商家；看匿名度，透明代理会把你的真实 IP 送给目标站；看 IP 纯净度，被滥用的段早晚被封；看售后与更换，IP 失效能不能快速处理；警惕超低价，远低于市场价的“独享住宅 IP”多半是共享或者 IP 池复用。

最后一条要补一句：超低价产品不是不能买，是要知道自己在买什么。二十几块钱一个月的共享出口，拿来试水、跑通流程完全够；拿它养一个已经投入几个月的账号，就是在赌邻居不作死。

## 常见问题

**静态住宅 IP 和动态住宅 IP 怎么选？**
要长期固定出口、养号、防关联，选静态；只是试水、临时注册、不介意 IP 每天定点更换，选动态，价格能低一个量级。但动态换 IP 意味着账号的登录地一直在漂，长期账号最好别这么干。

**独享和共享的差别到底有多大？**
共享出口上，别人跑什么你管不了。邻居被平台标记，同一个 IP 段跟着降权。独享贵出来的那部分钱，买的是“出事概率低”，不是“速度快”。

**为什么有的只要几元有的要几百？**
几元的是按单个 IP 计费的入门代理池，几百元的是整台真家宽 VPS。计价单位不同，不是同一种商品。同品牌内部也一样，61.2 元的双 ISP 和 899 元的加州家宽，差的是 IP 出身和带宽。

**年付真的比月付省吗？**
省，但省的是配置。日本线年付版 899 元对比月付 2028 元，省 1129 元，代价是带宽从 300Mbps 降到 100Mbps、流量从 3000GB 降到 1000GB。流量吃不满就值，吃得满就不值。

**ping 不通是不是线路坏了？**
丽萨主机日本 ISP 静态住宅 IP 的页面上写得很清楚：应 IP 提供方要求该 IP 段禁 ping，不能 ping 是正常的。测业务端口比测 ICMP 靠谱。

**能装 Windows 吗？**
官方标注支持安装 Windows，Linux 发行版也可以。

**双 ISP 和真家宽有什么区别？**
名字不同，价格差近三倍，差别在 IP 的来路。行业里对“ISP 代理”有两种实现：民宅拉真实宽带，或者数据中心托管但 IP 段由合作 ISP 分配。两种都合规，成本和稳定性不一样。想知道自己买的是哪种，最直接的办法是要一段测试 IP，自己查 ASN，再看第三方 IP 类型库怎么标。

**买了不满意能退吗？**
看线。韩国线写的是 48 小时不满意无条件退款，日本线是特殊产品只退网站余额。同一个品牌不同产品线条款不同，别按一条线的规则去推另一条。
